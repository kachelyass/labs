# Лабораторная работа 4

Тема: разработка семантического анализатора.

## Что делает программа

Модуль `main.go` выполняет полный цикл обработки тестовой программы:

1. читает очищенный исходный файл `../lab1/output.txt` или файл, переданный аргументом командной строки;
2. выполняет лексический анализ;
3. строит AST методом рекурсивного спуска;
4. выполняет семантический анализ AST;
5. формирует таблицу символов;
6. проверяет семантические ошибки;
7. строит промежуточное представление в виде триад.

## Запуск корректной программы

```bash
cd lab4
go run . ../lab1/output.txt
```

Если аргумент не передан, программа сама попробует найти `../lab1/output.txt`.

## Запуск примера с семантическими ошибками

```bash
cd lab4
go run . bad_semantic_test.go
```

## Запуск без модулей

Если Go будет ругаться на корневой `go.mod`, можно запустить без модулей:

```bash
cd lab4
GO111MODULE=off go run main.go ../lab1/output.txt
```

Итоговый пример успешного вывода сохранён в `output.txt`.
