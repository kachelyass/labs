# Лабораторная работа 4

Тема: разработка семантического анализатора.

## Что делает программа

Модуль `lab4/main.go` выполняет полный цикл обработки тестовой программы:

1. читает `../lab1/output.txt`;
2. выполняет лексический анализ;
3. строит AST методом рекурсивного спуска;
4. выполняет семантический анализ AST;
5. формирует таблицу символов;
6. проверяет семантические ошибки;
7. строит промежуточное представление в виде триад.

## Запуск

Из корня репозитория:

```bash
cd lab4
go run .
```

Если Go будет ругаться на корневой `go.mod`, можно запустить без модулей:

```bash
cd lab4
GO111MODULE=off go run main.go
```

Перед запуском проверь, что существует файл:

```text
lab1/output.txt
```

Итоговый вывод сохраняется в `lab4/output.txt` в архиве как пример работы.
